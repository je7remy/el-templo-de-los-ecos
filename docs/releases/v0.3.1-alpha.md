# El Templo de los Ecos — v0.3.1 Alpha

> **Primera versión alpha publicada como release del proyecto fuente.** No es un videojuego terminado ni un ejecutable precompilado.

## ¿Qué incluye?

Esta versión consolida el prototipo del **primer piso**, construido en Godot 4 con GDScript. Incluye **cinco habitaciones**, exploración e interacción, recolección de almas, una misión y entidades experimentales cuya supervivencia depende de comprender sus reglas.

El mundo es un templo que oculta una maquinaria de explotación de almas. El ciclo de muerte y reencarnación tiene dos posibles desenlaces (50 % por cada opción): conservar el alma, la memoria y las habilidades adquiridas —cuyos niveles regresan a cero—, o sufrir una absorción definitiva y continuar posteriormente con un nuevo humano.

### Recursos originales integrados

- **Knowledge Temple**, de **pingupollas**, para las salas, superficies y decoración (crédito obligatorio).
- **GothicVania Church Pack**, de **Luis Zuno / Ansimuz**, para los enemigos **Angel, Burning Ghoul y Skeleton Wizard** (publicación CC0 en OpenGameArt).

## Cómo probarlo en Fedora

1. Descarga **Source code (zip)** de esta release y descomprímelo, o clona el repositorio.
2. Instala **Godot 4.3 o superior**.
3. Desde la carpeta del proyecto, ejecuta:

```bash
godot --headless --path . --import
godot --path .
```

También puedes usar `bash herramientas/abrir_fedora.sh` para abrir el editor y pulsar **F5**. Para una instalación Flatpak, ejecuta `flatpak run org.godotengine.Godot` con los mismos argumentos.

## Estado y advertencias

- **Alpha / prueba vertical**: no hay exportaciones binarias para Linux, Windows o Android en esta release.
- Los enemigos y la misión tienen parámetros provisionales; **no todo constituye canon narrativo**.
- Los fondos son composiciones de sprites: **no** son mapas TileMapLayer editables.
- Las pruebas automatizadas verifican escenas, salas, misión y sprites, pero no sustituyen pruebas jugables manuales.
- Godot puede emitir una advertencia residual al cerrar la prueba sin interfaz; no se ha resuelto por completo.
