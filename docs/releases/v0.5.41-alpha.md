# El Templo de los Ecos — v0.5.41 Alpha

## Novedades
- **Salas más variadas**: cinco distribuciones nuevas (columnas, capilla, galería de estatuas, refectorio y cripta). Ya no se repite la misma sala dos veces seguidas.
- **More varied rooms**: five new room layouts; the same layout never appears twice in a row.

No cambia ninguna regla del juego ni el guardado: tu partida sigue igual. Si tienes una versión anterior (desde la 0.5.9), el juego te ofrecerá esta al abrirlo.

## Descargas
- **Android:** `ElTemploDeLosEcos-v0.5.41-alpha-Android.apk` (ARM64).
- **Windows 10/11 (64 bits):** `ElTemploDeLosEcos-v0.5.41-alpha-Windows-Setup.exe` o `…-Windows-Portable.zip`.
