# El Templo de los Ecos — v0.5.38 Alpha

## Novedades
- **Android con firma fija**: desde esta versión, cada APK nuevo se instala encima del anterior y conserva tu partida.

**Importante en Android (solo esta vez):** los APK anteriores se firmaron con una llave temporal, así que para instalar este hay que **desinstalar primero el juego**. Al desinstalar, Android borra la partida guardada en el teléfono. A partir de aquí las actualizaciones se instalan encima sin perder nada.

En Windows y Linux no cambia nada: el juego te ofrecerá esta versión al abrirlo, como siempre.

## Descargas
- **Android:** `ElTemploDeLosEcos-v0.5.38-alpha-Android.apk` (ARM64).
- **Windows 10/11 (64 bits):** `ElTemploDeLosEcos-v0.5.38-alpha-Windows-Setup.exe` o `…-Windows-Portable.zip`.
- **Linux (x86_64):** `ElTemploDeLosEcos-v0.5.38-alpha-Linux-x86_64.tar.gz`.
