# El Templo de los Ecos — v0.5.40 Alpha

## Novedades
- **Todo el juego en inglés**: con el idioma en inglés ya se traducen las salas, los diálogos, las misiones, los avisos, el perfil, la tienda y toda la Vigilia, no solo los menús.
- **English**: with the language set to English, the whole game is now translated — rooms, dialogue, missions, messages, profile, shop and the whole Vigil, not just the menus.

No cambia ninguna regla del juego ni el guardado: tu partida sigue igual. Si tienes una versión anterior (desde la 0.5.9), el juego te ofrecerá esta al abrirlo.
