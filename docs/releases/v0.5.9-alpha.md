# El Templo de los Ecos — v0.5.9 Alpha

## Novedades
- **Actualizaciones automáticas.** Al abrir el juego, si hay una versión nueva, el menú lo avisa. ACTUALIZAR la descarga e instala:
  - Windows (instalador o portable) y Linux: se reemplaza el juego y se vuelve a abrir solo.
  - Android: se abre la descarga del APK para confirmar la instalación.
  - La partida se conserva. Se puede apagar en Configuración > Sonido.
- **APK con firma fija** (si el repositorio tiene configurada la llave): las próximas versiones se instalan encima sin desinstalar.

## Importante: esta versión se instala a mano una vez
Las versiones anteriores no tenían actualizador, así que la 0.5.9 se instala como siempre. A partir de aquí, el juego avisa solo.
- **Android:** si la llave fija ya está configurada, esta versión cambia de firma: **desinstala la anterior una vez** (se borran los datos locales) y luego instala esta. Las siguientes ya se instalan encima.
- **Windows:** instala el `Setup.exe` encima de la versión anterior.
- **Linux:** descomprime y ejecuta `./instalar.sh`.

## Descargas
- **Android:** `ElTemploDeLosEcos-v0.5.9-alpha-Android.apk` (ARM64).
- **Windows 10/11 (64 bits):** `ElTemploDeLosEcos-v0.5.9-alpha-Windows-Setup.exe` o `…-Windows-Portable.zip`.
- **Linux (x86_64):** `ElTemploDeLosEcos-v0.5.9-alpha-Linux-x86_64.tar.gz`.
